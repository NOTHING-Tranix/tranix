# Tranix

Verified road-freight platform for India. Monorepo-style folder:

- `backend/` — Spring Boot (Java 21) API, jobs, public pages
- `frontend/` — Flutter app (Android first; web later)
- `docs/` — shared product spec, API contract, decisions, open questions, progress log
- `ROADMAP.md` — milestone order; `CLAUDE.md` — how Claude Code works on this project

Start Claude Code in this folder and run `/status`, then `/next-milestone`.
